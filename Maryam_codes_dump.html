HTML Attributes

    Attributes are extra information added to an HTML tag to control it's behaviour or apperance.
    They always go inside the opening tag and usually come in a name="value" format.
    Some common attribute include:

  • The a(anchor) tag attribute which is mostly used to describe hyperlinks such as;

    • Follow Maryam


  • The img definite attributes.These attributes belong only to the img, videos, and iframe elements, they are used to describe image in a webpage. for example the src, alt, width and height are attriutes for images;
  • Image as a link
    The image below is a link

  • The id attribute is used to give a unique identity to an element which cannot be duplicated throughout the webpage. ITt helps in identifying the element when linking or styling.

    • This is an id for my testpage and I can identify it while styling.

  • The class attributewhich can be used to group elements together for styling or js, while the id attributeis used to identify a unique element, the class elementis used to identify series or groups of elements

    • this is an highlighted paragraph. The class="highlight" can still be used again on the page, all element classified as highlight can then be identified during styling or js. There can also be any value attached to the class attribute such as my_text as in the case of id

  • The title attribute which is used to show a tooltip on hover. It is used to describe some extra information about an element. For example;

    • Hover over me

  • The lang attribute.This attribute is used to inform the browser about the language of the web page and it is mostly used with html element.

    • Hiiiii,My name is Maryam

    Bonjour,je m'apelle Maryam

  • The style attributewhich is used during inline CSS to style an element. For example;

    • This is a red paragraph.

  • NB: The above are examples of attributes, although there are also some otther attributes that are definite like the value, and place holder attributes used for some definites element like the input element used during Form.

HTML Formatting Elements

  • The b tag is use to bolden a text.
  • The strong tag is used for important text.
  • The i tag is used for italic texts.
  • The em tag is used for emphas ized texts.
  • The mark tag is used for marked texts.
  • The small tag is used for smaller texts.
  • The u tag is used for underlined texts.
  • The del tag is used for deleted texts.
  • The ins tag represents an inserted text.
  • The sub tag represents a subscript text and can also be used in writing chemical formulas.
  • The sup tag represents a superscript text and can also be used in writing math text.
